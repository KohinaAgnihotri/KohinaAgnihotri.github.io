# Kohina Agnihotri — Portfolio

Personal marketing portfolio. Single-page site, no build step.

## Files
- `index.html` — the whole site
- `assets/kohina.jpg` — portrait (add this; the "K" placeholder shows until it exists)
- `assets/Kohina_Agnihotri_Resume.pdf` — résumé linked from the Résumé buttons

## Publish on GitHub Pages
1. Create a public repo named `<your-username>.github.io` (gives you the cleanest URL).
2. Upload `index.html`, `README.md` and the `assets/` folder.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
4. In a minute or two the site is live at `https://<your-username>.github.io`.
